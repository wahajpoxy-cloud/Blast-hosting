# CPvP Minecraft Server

GitHub stores files; it does NOT run a Minecraft server 24/7. An always-on machine/VPS is required.

Folders: `mods/`, `plugins/`, `world/datapacks/`, `config/`.

`max-players=100` is configured, but actual 100-player performance depends on CPU/RAM/network.

For mods + plugins together, use a compatible hybrid server implementation for the exact Minecraft version and test compatibility. Do not upload proprietary/pirated files to GitHub.
